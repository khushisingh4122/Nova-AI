# Nova AI

Nova AI is a modern AI-powered chatbot built using Next.js, TypeScript, Tailwind CSS, and Google's Gemini API. The application provides intelligent, real-time conversations through a clean, responsive, and user-friendly interface.

## Features

* AI-powered conversations using Google Gemini
* Modern and responsive user interface
* Fast and lightweight performance
* Real-time chat experience
* Mobile-friendly design
* Dark mode support
* Clean and intuitive user experience
* Secure API integration

## Getting Started

### Installation

Clone the repository:

```bash
git clone https://github.com/khushisingh4122/Nova-AI.git
cd Nova-AI
```

Install dependencies:

```bash
npm install
```

Create an environment file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
